How was it done?

As you may as seen in the tags, there was a use of AI in making this website. Why use AI to make such a simple, minimal website? Well there's no real reasons. I was just lazy.

What did it generate? While I did make the design in figma, I've sent the AI to generate the CSS based on how I wanted my page to look like. At first, I also had an html page, though it generated a much better structured one that I adapted to my liking.

After that, it did help me to write some Javascript when MDN Web Docs wasn't enough. Like with generating a JSON file from metadata read inside each index.html for every blog posted.

Finally, I had it to generate the first test samples to test the listing with the JSON file. Which was strangely a real success.


Why making it?

Just a thought I had one day, at night, right before sleeping. More accurately, if I am to actually progress into cybersecurity, I kind of want to take a mental and "physical" note of what I did, what I could have done better, what I may have overlooked, etc.
