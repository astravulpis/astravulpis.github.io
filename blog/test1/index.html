Tags: infosec, gdpr, siem, zerotrust

1. Enumeration

Starting off with an Nmap scan to discover open ports and available services on the target machine.

nmap -sC -sV -oA nmap/doctor 10.10.10.209

2. Initial Foothold

Analyzing the web application hosted on port 80 revealed a user registration portal vulnerable to Server-Side Template Injection (SSTI).

3. Privilege Escalation

After acquiring a low-privilege shell, inspecting the local log files in /var/log/apache2/ exposed cleartext password credentials.

4. Deletion of the system

Once we aquire the password, we send a PHP request to the server with the credentials. In that PHP request, first we disable foreign keys contraints and then drops the table using:

EXEC sp_msforeachtable "ALTER TABLE ? NOCHECK CONSTRAINT all"
EXEC sp_MSforeachtable @command1 = "DROP TABLE ?"

This enables us to iterates through every table and drops them.

Simple in surface, it destroys everything in the database.
